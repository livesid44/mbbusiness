# mbbusiness

A .NET web application repository.

## Projects

### MbBusinessApp

A simple ASP.NET Core web application demonstrating API integration with query string parameters and button-triggered API calls.

**Features:**
- First API automatically called on page load with query string parameter support
- Second API triggered by button click
- Clean, responsive UI with real-time JSON response display

**Quick Start:**
```bash
cd MbBusinessApp
dotnet run
```

Visit `http://localhost:5000` or `http://localhost:5000/?message=Your%20Custom%20Message`

See [MbBusinessApp/README.md](MbBusinessApp/README.md) for detailed documentation.
